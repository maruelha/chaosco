# docs/archive — finished material [USER 2026-08-30]

Everything in here is **history**: it describes how something was planned or
reviewed at a point in time. It is kept because it explains *why* things look
the way they do — not because it is still true.

**Rules**

- Nothing in this folder is maintained. Do not update a file here after a
  feature changes; update the live doc instead.
- Never take a fact from here as current. Check the code or the live doc
  (`docs/screens.html`, `docs/database_schema.html`, `docs/architecture.html`,
  `docs/claude/*.md`, `docs/build_plan.md`).
- Move a doc in here when its work is done and the content has been folded
  into a live doc — a day plan that is executed, a review that is worked off,
  a session write-up, a concept that is now built.
